# 📚 Student Notes System (SNS)

A web-based Student Notes Management System developed using **Python Flask** to help students create, manage, organize, and maintain their academic notes efficiently.

🔗 **Live Demo:** https://sns-ekanth.codegnan.app/

## 🚀 Project Overview

The Student Notes System is designed to provide students with a simple and convenient platform to manage their study notes. It helps users keep their academic information organized and easily accessible through a user-friendly web interface.

## ✨ Features

- User Authentication
- Create and save notes
- View saved notes
- Edit and update notes
- Delete unwanted notes
- User-friendly interface
- Organized note management

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the Project Directory

```bash
cd student-notes-system
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Virtual Environment

**Windows:**
```bash
venv\Scripts\activate
```

**Linux / macOS:**
```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
